# Ocentra Hajj Travel — Assignment 1 starter project

This is a student-made HTML/CSS recreation inspired by the approved Ocentra Travel and Tourism Hajj packages website.

## Assignment 1 pages
1. `index.html` + `home.css` — Home page
2. `media.html` + `media.css` — Media and information page
3. `register.html` + `register.css` — Registration form

## Run locally
Open this folder in VS Code, then open `index.html` in a browser or use the Live Server extension.

## Important learning notes
- Each page links to its own stylesheet and all pages link to each other.
- The Media page includes image, video, audio, ordered/unordered lists, a table, box-model properties, background image, display, float, position-related layout and overflow.
- The Register page demonstrates form input types and validation attributes, pseudo-classes, attribute selectors and a pseudo-element.
- Some images and media files use remote sample URLs, so an internet connection is needed for them to display/play.
- This is a practice form only. It does not submit a real booking.
